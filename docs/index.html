    Reference pipeline on Google Cloud

    The prototype reads a static JSON file. In production, each stage below maps to a managed service.

    1. 1IngestListings, leases, transactions, CoStar/broker feeds, public macro data (FRED, Census)Cloud Storage, Dataflow
    2. 2ModelStaging, conformed market and property dimensions, quarterly KPI fact tablesBigQuery, Dataform/dbt
    3. 3ValidateAccounting identities (inventory, occupancy, absorption), freshness and anomaly testsDataplex data quality
    4. 4VisualizeGoverned metric definitions in one semantic layer, embedded dashboardsLooker, Looker Studio
    5. 5ExplainGrounded summaries and Q&A that cite the KPI tables; forecastsGemini on Vertex AI, BigQuery ML

    KPI definitions

    Example KPI view in BigQuery SQL

    The same net absorption and vacancy logic the dashboard uses, written as a warehouse view

    CREATE OR REPLACE VIEW cre.market_kpis_quarterly AS
SELECT
  market_id,
  property_type,
  quarter,
  inventory_sf,
  vacant_sf / inventory_sf                         AS vacancy_rate,
  occupied_sf - LAG(occupied_sf) OVER w            AS net_absorption_sf,
  deliveries_sf,
  SUM(deliveries_sf) OVER (w ROWS BETWEEN 3 PRECEDING
                              AND CURRENT ROW)     AS deliveries_t4q_sf,
  asking_rent_psf / LAG(asking_rent_psf, 4) OVER w
    - 1                                            AS rent_growth_yoy,
  cap_rate - t.yield_10y                           AS cap_spread
FROM cre.market_quarter_facts
JOIN macro.treasury_10y_quarterly AS t USING (quarter)
WINDOW w AS (PARTITION BY market_id, property_type
             ORDER BY quarter);

    How the AI features stay trustworthy

    • Every number in a summary is computed first, then put into words. The model never does the arithmetic.
    • The Gemini prompt contains only the current KPI table, and the model is told to say when an answer isn't in it.
    • The forecast is a damped Holt trend model with an error band. It is a transparent baseline, not a black box.
    • Anomalies are flagged when a quarter's vacancy change is more than 2.5 standard deviations from that market's own history.
