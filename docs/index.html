    Methodology

    Methodology and production architecture

    How every number is calculated, how the demo runs on Google Cloud today, and what would change for production.

    How this demo runs on Google Cloud

    The hosted demo runs on Cloud Run with data in BigQuery and Gemini on Vertex AI. This copy is static: it reads a bundled JSON file, and Gemini needs your own key.

    1. 1RefreshA loader job reloads the market, lease and market-name tables, then rebuilds the KPI views, at 6am ET on the 2nd of each quarter. Each run is logged.Cloud Scheduler, Cloud Run job
    2. 2ModelDataset cre: quarterly market facts, the lease portfolio and markets. KPI definitions live once, as SQL views.BigQuery
    3. 3ServeOne container serves this page and builds its dataset from BigQuery, cached for 5 minutes. If BigQuery is unreachable, it falls back to the bundled file.Cloud Run service
    4. 4AnalyzeKPIs, the vacancy forecast, anomaly flags and lease scoring are computed in the browser from that dataset.JavaScript, no dependencies
    5. 5ExplainQuestions and summaries go to the server, which sends Gemini only the on-screen KPIs. It runs as a service account, so no key is in the browser, and it is rate limited.Gemini 2.5 Flash on Vertex AI

    From demo to production

    • Real feeds: point the loader at research extracts, lease administration exports and macro data landed in Cloud Storage. Nothing downstream changes.
    • Quality gates: check accounting identities (inventory, occupancy, absorption), freshness and outliers before a load is published, with Dataplex data quality or tests in the loader.
    • Access: put the service behind company sign-in with Identity-Aware Proxy instead of a public link.
    • Delivery: deploy from the repository with a Cloud Build trigger, and alert on errors and spend with Cloud Monitoring and budgets.
    • Scale: add a semantic layer (Looker) if many teams need the same governed metrics, and BigQuery ML for forecasts at portfolio scale.

    KPI definitions

    The KPI view in BigQuery

    The live view behind the scorecard: latest quarter per market and type, with trailing-four-quarter sums and year-over-year changes

    CREATE VIEW cre.v_market_kpis AS
WITH q AS (
  SELECT *,
    SUM(net_absorption_sf) OVER w4            AS net_absorption_t4q_sf,
    SUM(deliveries_sf)     OVER w4            AS deliveries_t4q_sf,
    SUM(sales_volume_usd)  OVER w4            AS sales_volume_t4q_usd,
    vacancy_pct - LAG(vacancy_pct, 4) OVER w  AS vacancy_yoy_pp,
    SAFE_DIVIDE(asking_rent_psf,
      LAG(asking_rent_psf, 4) OVER w) * 100 - 100
                                              AS rent_yoy_pct,
    ROW_NUMBER() OVER (PARTITION BY market, property_type
                       ORDER BY quarter DESC) AS rn
  FROM cre.market_quarterly
  WINDOW w  AS (PARTITION BY market, property_type
                ORDER BY quarter),
         w4 AS (PARTITION BY market, property_type
                ORDER BY quarter
                ROWS BETWEEN 3 PRECEDING AND CURRENT ROW)
)
SELECT q.quarter, q.market, m.name AS market_name,
  q.property_type, q.vacancy_pct, q.vacancy_yoy_pp,
  q.net_absorption_t4q_sf, q.asking_rent_psf, q.rent_yoy_pct,
  q.cap_rate_pct,
  ROUND((q.cap_rate_pct - q.treasury_10y_pct) * 100)
                                              AS spread_to_10y_bps,
  SAFE_DIVIDE(q.under_construction_sf, q.inventory_sf) * 100
                                              AS under_construction_pct_inventory
FROM q JOIN cre.markets AS m ON m.id = q.market
WHERE q.rn = 1;

    How the AI features stay trustworthy

    • Every number in a summary is computed first, then put into words. The model never does the arithmetic.
    • The Gemini prompt contains only the current KPI table, and the model is told to say when an answer isn't in it. It runs at a low temperature with a capped answer length.
    • If Gemini is unavailable, a rules-based insight engine answers from the same data, so the assistant never goes blank.
    • The forecast is a damped Holt trend model with an error band. It is a transparent baseline, not a black box.
    • Anomalies are flagged when a quarter's vacancy change is more than 2.5 standard deviations from that market's own history.
